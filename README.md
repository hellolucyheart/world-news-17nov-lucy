**The World in One Day** — a single editorial poster that sums up the world news of Tuesday, 17 November 2026:

1. **Shenzhen Summit** — Trump, Xi and Putin gather for APEC and the first US–China–Russia trilateral meeting.
2. **Kerch Bridge struck** — Ukraine hits the Crimean Bridge again; a span collapses into the strait.
3. **Hormuz tanker ablaze** — the US strikes Iran's Qeshm Island as a gas tanker burns near the strait.
4. **AI chip curbs tighten** — Washington's new export licence rules land; stocks slide with Nvidia in focus.
5. **U.S. loses measles-free status** — PAHO ends nearly three decades of elimination status.

The artwork is a five-vignette collage (`artwork.webp`); `compose_poster.py` burns in the masthead and captions to produce `poster.jpg`. At grading time `main.py` — standard library only, no network — copies the poster to the output directory as `entry.png`, byte-for-byte, and prints a fixed action log, so every run is identical.

## Run it

```sh
python3 main.py   # writes entry.png to $MAKEFUN_OUTPUT_DIR (or ./output)
```
